# What Was That!?: инструкции для агента (бывший D-Cal)

Описание проекта, режимов и формата данных: `README.md`. Здесь только правила работы и чеклист.

## Правила

- Маленькие шаги, не переписывать то, что работает. Менять только то, о чём просят.
- Код простой и короткий, без лишних абстракций и зависимостей (зависимости только по согласованию).
- Swift, AppKit для окна, SwiftUI для содержимого, macOS 15+ (минимальная версия проверялась только компиляцией, на macOS 15 вживую не запускалось). Без Combine, async/await вместо него.
- Всё, что можно проверить кодом (парсер формата, данные), проверять тестами. Перед тестами собрать схему `MyApp`.
- Поведение окна (клики, Spaces, сон, фокус) агент проверить не может: писать минимум кода и ждать описания от пользователя. Не утверждать, что работает, пока пользователь не подтвердил.
- Если не уверен в поведении macOS API, сверяться с документацией Apple и честно говорить, что не проверено.
- Коммиты и пуши только по просьбе.

## Не ломать (проверено на Mac пользователя)

- Окно только на уровне обоев: locked — `desktopWindow + 1` (под значками), scroll/edit/move — `desktopIconWindow + 1`. Никогда `.floating`, `.statusBar`, `.screenSaver`. В locked `ignoresMouseEvents = true`.
- Режим accessory: ни Dock, ни Cmd-Tab, ни Mission Control.
- `collectionBehavior`: `.canJoinAllSpaces`, `.stationary`, `.ignoresCycle`, `.fullScreenAuxiliary`.
- Фокус: `NSApp.deactivate()` ненадёжен. Фокус возвращается явно приложению `lastExternalApp`. Окно переоткрывается только как крайняя мера после пяти неудачных попыток (`refreshCaret`). Фокус на поле ставится после появления полей и после того, как окно стало key.
- Esc в scroll — глобальный Carbon-хоткей только на время scroll. В edit и move — локальный монитор клавиш.
- Хоткей Opt+M через Carbon `RegisterEventHotKey` (не `addGlobalMonitorForEvents`: ему нужны разрешения).
- Данные: `~/Documents/what-was-that.json` (раньше `d-cal.json`, копируется при первом запуске), запись атомарная, битый файл не перезаписывать.
