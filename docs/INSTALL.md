# What Was That!? — установка и первый запуск

Календарь-лента дней на рабочем столе Mac: одна короткая строка на каждый день.

## Что нужно

- Mac с **macOS 15 (Sequoia)** или новее (на более старых системах приложение не запустится).
- Приложение не из App Store и пока не подписано Apple, поэтому при первом открытии Mac спросит подтверждение (см. ниже).

## Установка

1. Откройте скачанный образ (`.dmg`) и перетащите **What Was That** в папку «Программы» (или откройте `.zip` и перенесите приложение туда).
2. Первый запуск: в «Программах» нажмите на приложении **правой кнопкой → Открыть → Открыть**. Дальше оно открывается обычным образом.
3. Если Mac пишет, что приложение «повреждено» или его нельзя открыть: откройте «Системные настройки → Конфиденциальность и безопасность», найдите внизу сообщение про приложение и нажмите **«Всё равно открыть»**. Либо в Терминале:
   ```
   xattr -dr com.apple.quarantine "/Applications/What Was That.app"
   ```

После запуска в строке меню появится значок календаря. В Dock и в переключателе приложений (Cmd-Tab) приложения нет: так и задумано.

## Как пользоваться

| Что | Как |
|---|---|
| Режимы | **Opt+M** переключает Locked → Scroll → Edit → Locked. **Esc** возвращает в Locked из любого режима |
| Locked | Лента лежит на обоях, клики проходят сквозь неё |
| Scroll | Ленту можно листать колесом и жестами |
| Edit | Можно писать: клик по строке дня и текст. Стрелки вверх/вниз и Enter переходят на соседний день |
| Настройки | Значок в строке меню → **Settings…** |
| Двигать окно | Значок в строке меню → Mode → **Move**, потом тянуть мышью |

Данные хранятся в одном файле `~/Documents/what-was-that.json` (его можно положить в iCloud Drive: Settings → General → Data Folder).

## Разрешения (по запросу)

- **Календарь:** только если включить события календаря (Settings → General → Calendar events). Приложение их только читает.
- **Управление Notes:** только если подключить Apple Notes для заметки дня.

Если не включать эти функции, никаких запросов не будет.

## Удаление

Перенесите приложение из «Программ» в Корзину. Данные (`what-was-that.json`) остаются в «Документах»: удалите их сами, если нужно.
